Fresco PC Custom API

API REST para la primera entrega del TP Fullstack. La documentacion detallada tambien se encuentra en /docs/endpoints.md.

Base URL: http://localhost:5000/api
OpenAPI JSON: /api-docs/openapi.json

Recursos

Modulo Endpoints Objetivo
Productos GET/POST /api/productos
GET/PUT/DELETE /api/productos/:id		 Catalogo de componentes para armado de PCs.
Usuarios GET/POST /api/usuarios
GET/PUT /api/usuarios/:id		 Clientes con presupuesto y perfil de uso.
Armados GET/POST /api/armados
GET/PUT /api/armados/:id		 Configuraciones custom con validacion basica de compatibilidad.
Carritos GET/POST /api/carritos
GET /api/carritos/:id
POST /api/carritos/:id/items		 Gestor de compra temporal por usuario.
Pedidos GET/POST /api/pedidos
GET /api/pedidos/:id		 Checkout final a partir de un carrito.
